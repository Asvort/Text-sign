# [📘] Text sign
> Мод добавляющий таблички в игру.
>
> - Для редактирования удерживайте кнопку взаимодействия.
> - `\n` — перевод строки.
> - Не более 256 универсальных табличек на одной локации.
> - Динамический кэш — каждый пиксель занимает место на диске. Кэш хранится в папке мода.
> - Поддержка Anomaly Together 3 - кооператив (мультиплеер).
